# Product invariants

## INV-PRODUCT-001: No ads and no unrelated suggested content, anywhere in the product

Active · Decided: 2026-11-26, owner

No screen, surface, feed, empty state, notification, or API response in `yaai.os` may display advertisements, sponsored placements, upsells, or unrelated suggested content. Every item shown to the user must come from the user's own media, explicitly configured sources, or an explicit user query.

Explained in [[product/SKILL]].
